# Project 07 — WES Analysis Report

## Dataset

GSE179296 / SRP326537 / PRJNA743078, public NCBI WES dataset.

Pilot pair:

- Sample 1001 Normal — GSM5413848
- Sample 1001 Tumor — GSM5413849

The study used Agilent SureSelect Human All Exon V5 capture on Illumina HiSeq 2500 with 2 × 100 bp reads and hg38 processing. NCBI reports alignment with BWA-MEM, duplicate marking, GATK base recalibration, Mutect2, FilterMutectCalls and VEP/VCF2MAF annotation. citeturn1search0turn1search1

## Biological execution status

**Pending actual compute execution.**

The public FASTQ files are intentionally not stored in GitHub. The repository is prepared to retrieve them from SRA and run the complete workflow, but this chat environment does not have the user's AWS compute session or a local Sarek/Docker runtime attached.

Therefore, no variant counts, QC values, coverage statistics or PASS-variant totals are presented as if they came from our pipeline.

## Validation reference

NCBI provides processed information for this study, including the published supplementary mutation table. That information can be used as a **reference/sanity check** after running the raw-data workflow; it must not be presented as output generated by this repository.

## Interpretation boundary

This is a research/portfolio workflow. Variant calls are not clinical diagnoses, and clinical interpretation requires validated pipelines, appropriate controls, annotation and clinical/laboratory review.
