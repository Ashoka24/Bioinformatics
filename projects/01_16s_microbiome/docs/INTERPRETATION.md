# Interpretation framework

## One sample

A single run can demonstrate read counts, QC, feature generation, taxonomy assignment and descriptive diversity. It cannot establish disease association, enrichment between groups or a cohort-level biological conclusion.

## Cohort

After adding multiple samples with reliable metadata, the project can progress to alpha diversity, Bray–Curtis beta diversity, PCoA, PERMANOVA and compositional differential-abundance methods.

Use the sequence:

Observation → statistical evidence → biological plausibility → limitation

Keep these levels separate. High relative abundance in one sample is an observation, not evidence of disease enrichment.
