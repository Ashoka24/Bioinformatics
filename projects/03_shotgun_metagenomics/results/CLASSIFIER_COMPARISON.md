# Kraken2 vs Centrifuge comparison

The two classifiers were run on the same fastp-cleaned paired-end reads. Their abundance metrics are not assumed to be directly equivalent because the classifiers use different assignment and abundance procedures.

- Top-10 species overlap: 7/10
- Top-10 species Jaccard overlap: 0.5385

The TSV contains the top-10 union and the classifier-specific reported metrics.
